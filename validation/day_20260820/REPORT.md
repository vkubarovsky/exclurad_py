## 2. Главная находка дня — в измерителе, а не в генераторе

На 50К вылезли провалы там, где на 10К было чисто: J/ψ 8.0σ, φ 6.8σ,
ρ 12.0σ — все по Q², все в самом населённом бине. Выглядело как физика,
проявившаяся с ростом статистики.

Это был баг `delta_profiles.py`. В режиме сравнения форм он делил каждую
кривую на её собственное среднее, взятое по **своему** набору бинов.
Генератор населяет разрежённый хвост коробки; опорные точки, распределённые
по Борну, туда не достают. У J/ψ шесть бинов из одиннадцати имели события и
не имели опоры вовсе. Две кривые съезжали друг относительно друга, и вся
разница списывалась на бин с наименьшей ошибкой.

| ось Q² | было | стало |
|---|---|---|
| J/ψ | 8.0 | 1.1 |
| φ | 6.8 | 2.3 |
| π⁰ | 3.2 | 2.4 |
| ρ | 12.0 | 5.6 |

Это четвёртый случай подряд, когда два молчаливо несогласованных набора
дают ложную физику (до того: ключ кэша не знал о конвенции φ, затем об оси
t, затем о схеме разметки). Число безопорных бинов теперь печатается.
Коммит `e3ba04a`.

## 3. ρ: обрезание по неупругости

После исправления у ρ оставалось не выбросом, а **наклоном**: с
геометрическими бинами максимум 3.4σ при χ²/ndf 4.04, генератор давал δ,
падающее с Q² на 8% по коробке, квадратура — плоское.

Причина оказалась в постановке. У π⁰ и η обрезание задано (0.20), у J/ψ
задано (1.20), а у ρ и φ стоял **ноль** — то есть хвост интегрировался до
кинематического предела, где дифракционная модель экстраполируется далеко
за свой фит. Ни один реальный анализ так не режет.

Контрольный прогон, изменён ровно один параметр:

| | vcut = 0 (100К) | vcut = 0.20 (20К) |
|---|---|---|
| max \|pull\| | 3.4 | 2.3 |
| χ²/ndf | 4.04 | 2.04 |
| нижний бин Q² | +3.8% при ±0.4% | −1.9% при ±1.3% |

Избыток +3.8% при нынешней ошибке 1.3% дал бы 3σ; его нет.

**Значение 0.20 для ρ и φ — предположение по аналогии с π⁰ и η. Число за
VPK.**

## 4. J/ψ: приёмка, и это не баг

У J/ψ по Q² оставалось 10.1σ при среднем 1.0004 — то есть не сдвиг уровня,
а один бин.

В карточке J/ψ `iacc = jpsi`, у остальных четырёх — `none`. Отношение в
генераторе считается по событиям, прошедшим детектор; точная квадратура
приёмки не моделирует вообще. При включённом детекторе эти две величины
описывают разные вещи, и сравнивать их нельзя.

| ось | `iacc = jpsi` (100К) | `iacc = none` (20К) |
|---|---|---|
| Q² | 10.1 | 2.0 |
| W | 2.6 | 1.7 |
| \|t\| | 2.0 | 2.7 |
| φ | 2.2 | 2.0 |

Отсюда правило: карточки для сверки с точным расчётом обязаны идти без
приёмки. Боевая карточка J/ψ приёмку сохраняет.

## 5. Коробки G1: лечить надо коробку, а не сетку

Прямоугольник по (Q², W², t) не ложится в физическую область, потому что
окно по t **едет** вместе с обеими переменными:

| канал | t при cos θ\* = +1 гуляет в |
|---|---|
| π⁰ | −0.970 … −0.001 |
| η | −1.283 … −0.002 |
| ρ | −3.818 … −0.006 |
| φ | −3.913 … −0.005 |
| J/ψ | −1.784 … −0.451 |

Отсюда 52% запрещённых узлов и rms интерполяции 0.09 при допуске 0.02.
Запрещённые узлы заполнялись геометрическим средним годных — числом
ниоткуда. Ни измельчение сетки (девятикратное давало 18%), ни стратегия
заполнения не помогали, потому что чинили не то.

Рецепт: сужать (Q², W²), пока окно не перестанет ездить, и брать полосу t
сразу внутри самого строгого края.

| канал | Q² | W² | t | годных узлов | rms |
|---|---|---|---|---|---|
| π⁰ | 1.50–2.50 | 5.25–6.75 | −2.00 … −0.172 | 100% | 0.029 |
| η | 1.50–2.50 | 6.13–7.88 | −2.00 … −0.173 | 100% | 0.006 |
| ρ | 1.50–2.50 | 6.13–7.88 | −1.50 … −0.228 | 100% | 0.003 |
| φ | 1.50–2.50 | 7.00–9.00 | −1.50 … −0.252 | 100% | 0.002 |
| J/ψ | 0.02–0.20 | 19.90–20.35 | −1.60 … −0.554 | 100% | 0.005 |

J/ψ — тонкий слой у верха по W: у порога |t|min = 1.58 и падает до 0.46
только к W = 4.55. Верх коробки упёрся не в кинематику, а в собственный кат
карточки y < 0.99 (при W² = 20.4 выходит y = 0.991).

Стоимость события в новых коробках упала: J/ψ 798 мс против 2578,
π⁰ 1313 против 2973.

Коммит `d451d3a`.

## 9. Что осталось открытым

**Обрезание по неупругости у ρ и φ** — число за VPK. Сейчас в карточках G1
стоит 0.20 по аналогии.

**π⁰, интерполяция 0.029 при допуске 0.02.** Измельчение не помогает и в
чистой коробке: 1000 → 6144 узлов дают 0.029 → 0.027, при том что остальные
четыре канала сидят на 0.002–0.006. Особенность π⁰, не разрешения сетки. На
правильность не влияет — вторая ступень точная; влияет на скорость.

**π⁰ по |t|: χ²/N = 4.04** при максимуме 3.2σ — самая заметная оставшаяся
структура у псевдоскаляров. Смотреть на статистике G1.

**У ρ после обрезания остаётся χ²/N = 2.04.** На 20К это p ≈ 0.02, то есть
на грани. Смотреть на статистике G1.

**Мажоранта не разделяется между воркерами** — каждый строит свою заново.
Известно и отложено.
