## exclurad_py vs EXCLURAD vs an independent calculation (2026-10-08)
- v_cut ladders (diag_vladder.csv): the codes agree to <= 0.2 % for v_cut <= 0.03;
  the J/psi difference (up to 3 % in eta) builds up at v >~ 0.1 GeV^2, at Q2 = 1.5
  as at 0.03.  The earlier 0.2 % pi0/eta agreement was established at v_cut = 0.08 only.
- independent_tail.py (Dirac-spinor amplitude, own phase space; soft limit 5e-5):
  in EXCLURAD's bin (cm_angle) it agrees with EXCLURAD to ~1 % of the tail; exclurad_py
  is 8-18 % of the tail high.  Removing p_h(v)/p_h(0) from the independent code
  reproduces exclurad_py in every v interval: **exclurad_py's cm_angle mode omits the
  detected-hadron phase-space factor p_h(v)/p_h(0)** (frozen direction, energy
  following v: d3p/2E = (p/2) dE dOmega).
- Generator mode (J/psi detected, t fixed, p cancels in d3p/2E at fixed t): exclurad_py
  agrees with the independent calculation to 1-3 % of the tail, <= 0.35 % in eta
  (independent_tail_results.txt).  **The generator and the FT eta table are not affected.**
- cm_angle is the EXCLURAD-compatibility mode (published CLAS6 tables); the default
  baryon_detected t_kind="target" and all CLAS12 campaigns do not use it.
