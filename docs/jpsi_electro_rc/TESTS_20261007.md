## Radiative-integral precision near |t|_min — generator converged
In the generator's configuration (jpsi.diffrad_vm, J/psi detected) the default
RC_QUAD = 20,12,16,12 is converged next to |t|_min: eta at four points with
t' = 0.10-0.50 GeV^2 is 0.8982 0.9513 0.8773 0.8849, against 0.8983 0.9516
0.8773 0.8849 at 160,64,96,64 (0.03 s vs 6.2 s per point).

The 1.5 % non-convergence seen earlier the same day (0.838 vs 0.851) belongs
to the PROTON-detected wrapper used only for the EXCLURAD comparison
(validation/jpsi_exclurad_fortran/compare.py, t_N held fixed with a frozen CM
angle): there the model's |t|_min edge falls inside the v integral.  That
comparison must use a fine RC_QUAD; the generator need not.
