# Production runs — what exists, what changed, where it is

One entry per production campaign, newest first. Every number here is read
from the samples themselves (LUND headers, `config.json`, the wd_14tb
catalogue), never typed from memory.

**Adding an entry is part of finishing a run.** The recipe:

```bash
python3 production/lund_kinematics.py "<dir>/born/lund_osg/*.lund" born.npz 24
python3 production/lund_kinematics.py "<dir>/rad/lund_osg/*.lund"  rad.npz  24
python3 production/run_report.py born.npz rad.npz <tag> docs/plots
python3 production/shape_steps.py born.npz rad.npz "<tag>"      # sampler test
```

`run_report.py` fixes the figure on purpose: the same six panels on the same
axes for every run, so two runs can be laid side by side. Panel 6 is the
rad/born shape test against the majorant cell edges — the test that caught the
2026-09-25 sampler bug, and the reason it is on every page now.

## 2026-09-25/26 — `rga_fa18_inb_t2` — RG-A fall 2018 inbending, through GEMC

**Status: current.** The first sample with an unbiased radiative shape.

| | |
|---|---|
| channel, model | π⁰ off the proton, `pi0.amp2609` |
| beam, target | 10.604 GeV, LH2, vertex z −5.5…−0.5 cm |
| box | W² 3.24–16.0, Q² 0.80–10.0, t −2.00…−0.001, vcut **0** |
| events | 1 000 000 born + 1 000 000 rad, 200 chunks × 5000 each |
| σ | born **0.8804 nb**, obs **1.0798 nb** → ⟨η⟩ = **1.226** over the box |
| code | born `225d4d9`, rad `291fe5f` (the difference is the cards commit; the physics code is identical and carries the stage-2 fix) |
| generated on | clonfarm11, 100 workers, born 8 min, rad 9 h 21 min |
| simulated | gemc 5.13 + coatjava 10.0.7, `rga_fall2018`, torus −1.00, **50 nA background merged over 11 detectors** |
| output | DST 23 GB born / 20 GB rad, flat ntuple 50 float32 per event |
| plots | `docs/plots/rga_fa18_inb_t2_20260925_overview.png` |

**What is new in this run**

1. **The stage-2 composition fix** (`225d4d9`). Every earlier radiative sample
   has its shape divided by the per-cell bound `B_cell`. Measured on this run
   at full statistics, the same 1M+1M as the broken one:

   | | worst at a majorant cell edge | worst at a control point |
   |---|---|---|
   | before | **19.2 σ**, −22.0 % at W = 2.20 | 2.2 σ |
   | after | **2.0 σ** | 1.6 σ |

   Cell edges are no longer distinguishable from arbitrary points.
2. **Narrower t box**, −5.0 → −2.0 GeV². Igor's CLAS12 grid spans |t| =
   0.125–1.758 with nothing above 2.0, and amp2609 stops being valid at 1.8.
3. **vcut = 0 with the tail kept**, so the missing-mass cut is applied after
   GEMC on the *reconstructed* MX². Resolution migration across the cut is
   then simulated rather than assumed. A cut at v < 0.17 keeps 72.8 % of
   events; v < 0.05 keeps 65.3 %.
4. **σ reported from stage 2.** It used to be a stage-1 quantity
   (∫ b·η_capped) for a sample distributed as σ_exact. **`sigma_nb` of this
   run is therefore not directly comparable with earlier runs.**
5. Background merged over eleven detectors, not bg-merger's default `DC,FTOF`
   — otherwise the calorimeter stays clean exactly where the π⁰ photons are.

**Caveats to carry with the sample**

- The box exceeds amp2609's validity (Q² 1.15–8.31, |t| ≤ 1.8): **47 % of
  events have Q² < 1.15**, below the lowest point of Igor's data. The model
  extrapolates there and says so (`sf.out_of_range: report`).
- About **0.25 % of rad events exceed the stage-2 bound** (worst ×1.55), so
  the sample is not strictly unweighted in that tail.
- **The step at v = 10⁻⁴ in the radiative-tail panel is `vmin`**, the
  soft/hard split, not a defect. Below it only the external pre-vertex
  radiator contributes: born, which has no internal radiation at all, shows
  the same 0.8 % per decade flat in log v from 10⁻⁶ to 10⁰ — the signature of
  the straggling law `loss = u^(1/bt)`, whose density goes as `1/loss` for
  small `bt`. Above 10⁻⁴ the internal hard tail switches on and outweighs it
  by an order of magnitude (rad/born 0.44 below, 8.9 just above). Internal
  photons softer than `vmin` are absorbed into the exponentiated soft factor
  and the event is written with v = 0, which is what makes the edge sharp.
  It is harmless: 10⁻⁴ GeV² is two to three orders of magnitude below the
  CLAS12 missing-mass resolution, and the whole region below it holds 1.1 %
  of radiative events.
- Reconstructed W and Q² run past the box edges (W to 4.25, Q² to 11.5)
  because `itarg=1` puts a pre-vertex radiator in front of the target and the
  kinematics are reconstructed at the nominal beam energy — which is what a
  detector sees.

## 2026-09-24 — `rga_fa18_inb` — first two-stage GEMC attempt

**Status: superseded. Do not use the radiative half.**

1 000 000 born + 1 000 000 rad, same channel and beam, box t **−5.00**…−0.001.
Generated on clonfarm11 and staged to `/volatile`. Its 400 GEMC jobs were
cancelled on 2026-09-25 before they ran.

Superseded twice over: the radiative half carries the stage-2 shape bias (this
is the sample the bug was measured on), and the box is the wide one. The born
half is physically fine — Born mode never enters stage 2 — and 96.0 % of it
survives a |t| < 2 cut, so it is usable if anyone needs it.
